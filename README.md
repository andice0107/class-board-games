# 桌遊對戰教室

老師開房間、學生掃 QR code 加入，用自己的平板或手機和同學對戰的桌遊平台。

- `index.html`：老師首頁，選遊戲開房間
- `host.html`：老師房間（QR code、自動配對、各桌即時畫面、積分榜、教師說明）
- `play.html`：學生端
- `games.js`：遊戲清單；每個遊戲放在 `games/<遊戲>/`，只在被選到時才載入
- `net.js`：透過免費公開 MQTT 伺服器連線（網址加 `?local=1` 可在同一台電腦用分頁測試）

## 目前的遊戲
- 天使與惡魔（社會技巧卡牌，andice 原創構想）
- 你說我接（社會技巧・對話接話卡牌：念題、出回應牌、匿名投票；題目與回應皆原創）
- 中國象棋（完整規則、悔棋／和棋／認輸、學生版與教師版說明）
